# PRD — 慢慢记 (ManManJi) 备考系统

## 需求清单

| ID | 需求 | 验收标准 |
|----|------|---------|
| R01 | 8大考试品类支持 | 中级经济师/会计师/教师资格证/社工/二建/人力/税务师/初级会计师，每品类独立题库和学习进度 |
| R02 | 艾宾浩斯智能复盘 | 遗忘曲线自动推送复习，间隔: 1天→2天→4天→7天→15天→30天；用户标记掌握后从队列移除 |
| R03 | 考点分级速记 | 考点分必考/理解/了解三级，每条配4-8字记忆口诀+白话解读 |
| R04 | 碎片音频听学 | 所有考点配套慢速音频，支持后台播放+字幕同步 |
| R05 | 精简真题题库 | 仅保留近5年高频真题+核心必考题；错题配套口语化解析+口诀；错题自动收集到错题本 |
| R06 | 三端统一(PC+H5+小程序) | 用户数据/会员/进度/错题/收藏全域实时同步 |
| R07 | 三级会员体系 | 免费(基础考点+限量真题)+单科会员(¥39.90/科/年)+全站通卡(¥99/年全品类) |
| R08 | 微信支付 | Web端API+H5支付+小程序JSSDK；服务端计算金额；回调签名验证+幂等处理 |
| R09 | 大龄关怀UI | 字体缩放三档(标准/中等/大号)；护眼模式；触控≥44px；对比度≥4.5:1；所有操作≤2步 |
| R10 | PC端批量资料下载 | 讲义/口诀手册/考点清单 PDF下载 |
| R11 | 大屏全真模考(CBT) | 45分钟倒计时；选项随机排列；交卷即时出分+错题解析 |
| R12 | 全站关键词搜索 | 跨科目检索考点/口诀/解读 |
| R13 | 多科目并行备考看板 | 同时展示多个考试科目的学习进度 |
| R14 | 教研内容实时同步 | PC编辑→Mobile即时推送，内容变更后秒级同步 |
| R15 | 用户打卡 | 每日打卡记录+连续打卡统计 |

## 技术栈

- 前端: Vanilla JS + HTML + CSS (SPA架构，组件化)
- 后端: Node.js + Express
- 数据库: MongoDB + Redis 缓存
- 实时同步: WebSocket / Firebase Realtime Database
- 支付: 微信支付 V3 API
- 部署: Docker Compose (Nginx + Node + PM2 + MongoDB)

## 非功能需求

- 性能: 页面加载<2s，音频播放稳定支持后台缓存
- 安全: 支付金额服务端校验；回调签名验证；无客户端密钥泄露
- 兼容: 适配全型号手机/电脑/全版本微信
- 可访问性: Lighthouse≥90，axe-core 0违规

## UI 方向

- 风格: 极简低干扰，大龄友好
- 配色: 低饱和暖色系+护眼模式
- 字体: Outfit(标题) + Inter(正文)，最小16px
- 响应式: 375px / 768px / 1440px 三断点
