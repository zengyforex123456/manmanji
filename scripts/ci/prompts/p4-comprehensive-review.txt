执行 P4 综合审查。以 PASS 或 FAIL 作为报告第一行。

## 步骤

1. **PRD 追溯**: 如果有 .claude/prd.md，输出 需求ID → 代码文件 → 测试 的对应表。标注缺失的链接。
2. **安全检查**: 检查代码中是否有：
   - SQL 注入（字符串拼接 SQL）
   - XSS（innerHTML、未转义的用户输入）
   - 目录遍历（未验证的文件路径）
   - 硬编码密钥（API key 明文在代码中）
   - 日志泄露（console.log 打印密码/token）
3. **集成一致性**: 检查模块间接口是否匹配，有无重复函数定义，有无命名冲突。
4. **依赖安全**: 检查 package.json 中的依赖版本是否有已知漏洞。

## 输出格式

```
PASS 或 FAIL
- PRD 追溯: 完整/不完整 (X/Y 需求有代码和测试)
- 安全: 通过/X个高危/Y个中危
- 集成: 通过/X个冲突
- 依赖: 通过/X个漏洞

如果 FAIL，列出所有问题，按严重度排序（Critical > High > Medium）。
```
