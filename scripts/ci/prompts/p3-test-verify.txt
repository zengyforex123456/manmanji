执行 P3 测试验证。以 PASS 或 FAIL 作为报告第一行。

## 步骤

1. 运行项目测试套件（npm test 或等价命令）
2. 提取覆盖率数据
3. 对照 PRD 需求，检查是否有需求缺少测试
4. 如果涉及 UI，检查是否有响应式测试（375/768/1440px）

## 输出格式

```
PASS 或 FAIL
- Tests: X passed / Y failed / Z skipped
- Coverage: 行 X% / 分支 Y% (目标: 行≥80%, 分支≥70%)
- PRD 覆盖: R1✓ R2✓ R3✗ (如果有 PRD)
- UI 测试: （如果适用）通过/失败

如果 FAIL，列出失败的测试和未覆盖的 PRD 需求。
```
